# Legacy YAGNI Rationale

Retained for older plans; never select separately. New work states KISS and
lists hypothetical features, options, hooks, backends, or extension points under
**Deferred**.

Deferral cannot remove requested outcomes, explicit constraints, established
conventions, or work required by correctness, security, accessibility, data
integrity, performance, or compatibility evidence. Explain the trade-off before
dropping explicitly requested speculative work. Restore deferred items when
later evidence requires them; ask only when crossing the resolved Focus Record's
authority boundary.
